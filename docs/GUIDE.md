# 使用、保管与迁移

## 第一次使用

拖入少量文件，默认保留原位置建立索引。托管复制会另外保存经过 SHA-256 校验的副本，需额外空间。导入在后台运行，可以在“设置 → 后台任务”查看逐项结果；任务完成不等于所有格式都已抽出正文。

分类是索引归属，不会搬动磁盘文件。可建 9 级分类，侧栏边缘拖动排序，中间拖入子分类；Option+↑/↓ 调整同级顺序。分类移动也会影响按父分类设定的 AI 可见范围。

“发现磁盘资料”只列候选，勾选并预览后才入库。分类规则只按文件信息匹配，不推断正文主题。原文件被修改后需增量扫描或再次提交；Agent 单文件来源默认不持续观察。

## 搜索与引用

主界面用于日常找文件，“设置 → AI 知识库”可检索段落、筛选分类和标签、配置 AI 可读范围。检索结果应读回目标段落并核对文件 SHA 与提取 SHA，不能把附近文本当作结论证据。资料中的命令仅是内容，不应被 Agent 自动执行。

图片、PDF、HTML 可应用内阅读；HTML 会移除脚本和外部资源，布局不一定与浏览器原页相同。扫描 PDF 可在详情中运行本地 OCR。受保护或超限文件仍保留原件，并显示正文未就绪原因。

## 保管方式

| 方式 | 保护范围 | 注意事项 |
|---|---|---|
| 托管复制 | 当前磁盘上的原件副本 | 与原件同盘不构成独立备份 |
| `.vaultpack` | 资料交换、原件及部分分类标签 | 不包含全部笔记、授权、历史与规则；Android 分类仍为平面结构 |
| `.shiyuebackup` | 一致性数据库、托管对象、历史、笔记和回收站 | 未托管的外部原件只有清单，不包含文件内容 |
| 增量备份仓库 | 按内容复用对象，可选择纳入外部原件 | 优先选择另一块磁盘；仓库未加密，不自动删旧快照 |

恢复总是建立新目录；原库不覆盖，旧任务不会自动重跑，来源观察暂停。先核对文件、索引和外部原件，再切换使用。移动资料库必须先关闭应用，再复制完整数据目录；通过备份恢复更易验证。

升级前保留旧安装包和一致性备份。回滚时先关闭应用并保存当前库，再用旧 App 配合对应备份副本；不要把旧 SQLite 文件覆盖进运行中的新库。浏览器只是界面，个人库不依赖浏览器存储。

## 问题定位

应用打不开时查看数据目录中的 `app.log`；不要把整份日志或数据库直接公开，先去掉个人路径、文件名、凭证和正文。启动后若提示已有实例，关闭另一个拾页窗口，再重新打开。外部原件离线时仍可检索已提取的原文，重新连接磁盘后再打开原件。
