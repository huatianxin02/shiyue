# 1.10.0 社区发行审查

审查日期：2026-11-15。目标是可独立构建、可核验、可公开分享的 MIT 社区发行。此记录不等同于独立安全审计或所有系统版本认证。

## 已处理的问题

| 问题 | 处理与验证 |
|---|---|
| 媒体 URL 携带所有者凭证 | 移除查询参数鉴权；单独的 HttpOnly / SameSite=Strict 媒体 cookie 只允许指定预览 GET/HEAD，不能调用管理或知识接口；回归与真实 HTTP 均验证 |
| PDF 组件落后于上游修复 | pypdf 从 6.20.0 升为 7.1.0，固定发行文件和源码哈希；更新原文许可 |
| 复杂文档处理可拖住主进程 | 独立解析进程、35 秒超时、取消退出、尽力施加 CPU/内存上限；Office XML 拒绝 DTD/实体，ZIP 拒绝重复或过量条目 |
| 托管视频不能稳定生成封面和时长 | 为无扩展名对象建立库内临时硬链接，向系统组件保留容器后缀；原件删除后仍能读取；对象 SHA 不变，无大文件复制 |
| 构建依赖开发机既有二进制 | 全部三个 Swift 助手从源码编译，App 在新目录组装，签名并写入源码指纹 |
| 开发目录混有个人资料和历史记录 | 显式发布白名单、隐私扫描、外部符号链接拦截；源码与 App 分别打包，附 SHA256SUMS |
| Android 脚本内有固定正式签名口令 | 正式签名改为外部密钥和环境变量；默认生成明确标为 debug 的构建；测试资料包由脚本临时生成 |
| 接入说明与版本限制不便迁移 | Agent 包 1.3.0 支持 1.9.x / 1.10.x、能力检查与便携自检；删除个人绝对路径 |
| 公开项目缺少基本维护材料 | MIT、贡献/安全指南、平台说明、固定依赖、第三方声明、组件清单、Issue 模板和 CI 配置 |

## 自动验证结果

本机环境：Apple Silicon，macOS 27.0.1（26A434），Xcode 27.0；App 内置 CPython 3.13.18。没有在 macOS 13 的真实系统完成兼容验收，因此 13+ 是编译部署目标，不是逐版本验证结论。

- Python 回归：239 项通过，覆盖资料索引、树形分类、导入/删除/恢复、备份、段落版本、权限过滤、磁盘发现、Agent 与公开发布边界。
- DOM 交互回归：50 项通过。
- Agent 便携自检：7 个接入文件通过哈希检查，隔离库测试通过；不会写入个人库。
- 真实 HTTP：所有者/媒体权限分离、官方 CLI 幂等入库、固定引用读回、备份恢复、删除外部原件后的托管网页阅读、分类重启保持均通过。
- 真实界面：由 App ZIP 解压的隔离副本通过原生设置快捷键、静态网页阅读、PDF 页图与阅读位置检查；浏览器验证图片大图、PDF 翻页及托管视频实际播放。预览 URL 不携带所有者凭证，浏览器记录未出现错误或警告。
- Android 桌面 JVM：自制 4 文件资料包往返、分类保留、重复导入与损坏包拒绝通过。Debug APK 与隔离 instrumentation APK 编译、签名校验通过；没有在手机/模拟器运行该 APK。
- 开发依赖 `npm audit`：本次查询返回 0 个已知漏洞；这一结果仅覆盖 npm 清单，不代表所有二进制依赖无漏洞。
- 公开源码从导出目录重建；未复用开发目录的 App 或原生助手。Python 归档使用已按锁文件验证的下载缓存，Node 依赖通过 `npm ci` 安装；不是在全新机器上从零联网下载的验证。
- 公开包检查：不含个人数据库、文档原件、访问描述文件、签名私钥和私有 QA；检查归档完整性、App 签名、源码指纹、内部符号链接与复制哈希。

App 采用临时签名；测试启动时禁止写入 Python 字节码，签名在执行后再次核验。

## 发行边界与后续优化

1. **社区分发**：当前材料可用于公开源码和社区包分享。尚无 Apple Developer ID 签名和公证；不能标作已公证安装包。GitHub CI 配置已经准备，本次没有上传仓库或运行远程 CI。
2. **平台覆盖**：下一阶段应建立 macOS 13/14/15/27 的安装、启动、迁移和无权限目录矩阵。Android 仍是历史实验端；Windows/Linux 尚无桌面交付。
3. **规模与体验**：增加 1 万/10 万文件基准、可取消的长任务进度、知识查询分页、稳定启动耗时记录、键盘与屏幕阅读器矩阵。这些属于后续工程，不能用小样本通过替代性能结论。
4. **知识检索**：先积累可公开的中文相关性与引用定位评测集，再决定是否引入可选语义模型或复杂解析器。当前没有向量检索；不把尚未实现的能力写入功能表。
5. **维护**：定期核对 Python、PDF 和分词上游公告；固定 vendor 与内置运行时不在 npm 自动更新范围内。组件清单记录主要运行依赖与开发依赖，运行时完整许可集合另行保留，未完成每个原生动态库的逐组件安全认证。

个人资料库的安装前一致性快照、迁移对比与私有验收日志由使用者本地保存，不随公开源代码分发。
